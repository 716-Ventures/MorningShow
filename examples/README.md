# Example Profile

These are the original starter preferences, provided as an illustrative example,
not a real listener's saved configuration. They are not loaded automatically.
Run `./show configure` to create your own profile under ignored `data/`.

Do not replace these examples with your personal profile or feedback. All runtime
profiles, editorial memory, backups, databases, and Codex auth state belong in
ignored `data/`. API keys belong in ignored `.env`, never in these examples.
